# Near Miss · 擦肩而过

> 发现我们的时空轨迹（时间 + 地点）与重大公共危险事件的潜在交集。  
> 从近在咫尺的“侥幸”，到同省邻域的“共同经历”，回望发生在身边的危险事件，是为了更懂得珍惜当下的幸福。

**本地桌面应用**

---

## ✨ 核心特性

| 功能 | 说明 |
| --- | --- |
| **主动时空查询** | 地名搜索 / 地图点击选点 + 时间段（滚轮式日期选择器），检索指定时空附近的危险事件 |
| **三圈层展示** | 擦肩而过（≤10km）/ 一衣带水（相邻地级市）/ 一箭之遥（同省 + 相邻省份） |
| **行政区划关键词增强** | 内置全国省市数据，检索时自动注入相邻地级市、相邻省份的具体名单，查全率更高 |
| **联网检索（可靠性优先）** | 调用你自己的大模型 API 实时联网搜索，每条事件强制要求可核实信源 URL，杜绝幻觉 |
| **结果缓存** | 相同查询秒回且结果完全一致（本地缓存，天数可调，一键清除） |
| **空白二次确认** | 某圈层首次检索为空时自动再检索一遍，两次为空才判定"确实没有" |
| **实时进度** | 查询时显示已用时计时，结果页展示本次检索耗时 |
| **离线模式（可选）** | 导入 EM-DAT 权威灾害数据库 CSV，完全本地检索，无需 API |
| **隐私与安全** | 位置数据仅在本机处理；API 密钥 AES-256-GCM 加密存储 |

## 🚀 快速开始

### 环境要求
- **Windows 10 及以上**。**无需手动安装 Node.js** —— 首次运行 `start.bat` 会自动下载便携运行时（约 30 MB，一次性）。
- macOS / Linux 用户：请先自行安装 [Node.js 18+](https://nodejs.org/)，再按下方命令启动。

### Windows
双击 **`start.bat`** 即可：首次运行会自动下载 Node 便携运行时并安装依赖，之后每次双击直接启动。

### 任意平台（命令行）
```bash
cd near-miss
npm install        # 首次
npm start          # 启动
```

启动后，应用会自动在浏览器打开 `http://127.0.0.1:17631/`。  
所有数据保存在 `~/.near-miss/`（设置 + 检索缓存），项目文件夹本身不存储任何个人数据。

## ⚙️ 配置（首次使用必读）

打开 **设置** 面板：

1. **填写大模型 API 密钥** —— 必须是 OpenAI 兼容接口密钥。
2. **API Base URL** —— 如 `https://api.openai.com/v1`、`https://api.deepseek.com` 等。
3. **模型** —— 建议选择支持联网检索的型号。
4. 按需调整最大事件数、请求超时、结果缓存天数。

> 💡 兼容推理类模型（如 deepseek 系列）：会自动从 `reasoning_content` 读取最终结果。  
> 💡 离线模式：前往 [emdat.be](https://www.emdat.be/) 下载 EM-DAT 公开 CSV 存档，在设置中导入并勾选"启用离线模式"即可完全离线检索。

## 🧭 使用流程

1. 在「时空查询」面板，输入地名（如"郑州市"）并点"定位"，或直接在地图上点击选点。
2. 用**滚轮**（或直接点击刻度）选择开始 / 结束日期，精确到日。
3. 点"开始查询擦肩而过"。模型会分三个圈层并行联网检索，状态栏实时显示已用时。
4. 在「结果」面板查看三层圈层结构 + 地图标记 + 本次检索耗时。

**三圈层定义**：
- **擦肩而过**：距离查询点 ≤ 10 公里 —— "我与危险擦肩而过。"
- **一衣带水**：所在城市的相邻地级市 —— "危险曾离我的生活圈很近。"
- **一箭之遥**：同一个省份，兼顾相邻省份 —— "我们共同经历过这场灾难。"

> 某圈层首次检索为空会自动二次检索确认；两次为空才会在备注中说明"未找到"。

## 🏗️ 项目结构

```
near-miss/
├── start.bat                  # Windows 启动器
├── package.json
└── src/
    ├── server.js              # Express 服务器（三圈层并行检索 + 路由 + 静态服务，仅监听 127.0.0.1）
    └── lib/
        ├── crypto-store.js    # AES-256-GCM 加密设置存储
        ├── geo.js             # 地理编码 + Haversine 距离 + 空间圈层判定
        ├── china-regions.js   # 全国省级行政区相邻关系 + 地级市名单
        ├── prompt-builder.js  # 单圈层结构化提示词（含相邻区域关键词增强）
        ├── llm-search.js      # OpenAI 兼容调用（兼容推理模型）+ 健壮 JSON 解析
        ├── result-cache.js    # 本地结果缓存（确定性重放 + 秒级重复查询）
        └── offline-emdat.js   # 离线 EM-DAT CSV 检索模块
    └── public/
        ├── index.html         # 三面板 GUI（查询/结果/设置）
        ├── css/app.css        # 浅色玻璃风格主题
        └── js/app.js          # Leaflet 地图、滚轮日期选择器、检索逻辑
```

## 🔒 隐私与安全说明

| 数据 | 处理方式 |
| --- | --- |
| 位置输入 | 仅在本机处理；**唯一**外发的是匿名化的"地名/坐标 + 时间"提示词 |
| API 密钥 | 使用 AES-256-GCM（PBKDF2 派生密钥）加密后存储于本地 `~/.near-miss/settings.json` |
| 查询请求 | 仅发送给你**自行配置**的大模型 API，不经过任何中间服务器 |
| 检索缓存 | 保存在本机 `~/.near-miss/search-cache.json`，超过缓存天数自动失效，可在设置中一键清除 |
| 离线模式 | 零网络请求，完全本地 |

> ⚠️ 加密存储是"静态混淆"级别的保护（防御文件被直接拷贝），不等同于全盘加密。若你的机器本身被完整控制，任何本地应用都无法保证绝对安全。
